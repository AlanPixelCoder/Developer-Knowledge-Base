## The Cabinet Guild

In the backroom of the Cabinet Guild sit rows of old browser arcade machines. Each run starts at cold boot: coin slot idle, service log waiting. JavaScript is the tool to talk to those machines — one instruction at a time — moving from console logs to a living HUD.

## Learning Path

1. **Boot** — Wake the cabinet with `console.log()`.
2. **Loadout** — Store values with variables and types.
3. **Gate** — Branch with conditionals and dice rolls.
4. **Cooldown** — Repeat with loops.
5. **Bin** — Organize parts in arrays.
6. **Routines** — Name work as functions.
7. **Roster** — Bundle data and behavior as objects.
8. **Backpanel** — Make the HUD respond to input.
