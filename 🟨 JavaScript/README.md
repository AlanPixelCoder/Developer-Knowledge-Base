**Note:**
This module is the Map of Content (MOC) for the JavaScript notes in this Obsidian vault. JavaScript is the language that makes web pages *do* things — from printing to the console and holding data in variables, through conditionals, loops, arrays, functions and objects, all the way to a living DOM that listens to the player. Every example is kept minimal and executable as-is: paste it in a browser console or a `.js` file and it runs.

**Tip:**
Start at [[01 - Insert Coin]]. Learn to print and hold values before you learn to loop and bundle them — once variables and types are muscle memory, everything else in this module is composition.

**Prerequisite:** [🌐 HTML MOC](../%F0%9F%8C%90%20HTML/README.md). Chapter [[08 - Living HUD]] rewrites pages built with the HTML course, so the structure vocabulary should already be familiar. [🎨 CSS MOC](../%F0%9F%8E%A8%20CSS/README.md) helps but is not required.

> [!NOTE]
> **The Emberfall narrative**
> Every exercise in this module belongs to the same fictional project: *Emberfall*, a roguelike.
> The shop receipt becomes a console log, fall damage becomes arithmetic, the dungeon die
> becomes `Math.random()`, the inventory becomes an array, the character sheet becomes an
> object, and the HUD becomes the DOM. Nothing about the syntax changes — which is the point:
> you learn one vocabulary and reuse it everywhere.

## 🎯 Learning Path

1. **Insert Coin** → talk to the machine: print values and document your code.
2. **Player Stats** → hold data: declare variables and know every type you will meet.
3. **Loot Rolls** → make decisions: conditionals, comparisons and randomness.
4. **The Farm** → repeat work: the two loop shapes and how to escape them.
5. **Inventory** → hold many: arrays and the methods that reshape them.
6. **Skill Functions** → name work: parameters, `return`, scope and arrow shorthand.
7. **Character Sheet** → hold meaning: objects, methods and `this`.
8. **Living HUD** → meet the player: the DOM, styles and event listeners.

---

## 🎯 What You'll Be Able To Do

- Print to the console and read errors like a map.
- Declare with `const` by default, `let` when values change, and name types on sight.
- Compute with arithmetic, comparison and logic — including `Math.random()` rolls.
- Drive decisions with `if / else if / else`, the ternary and `switch`.
- Repeat with `while`, `for` and `for...of`, using `break` and `continue` on purpose.
- Store ordered data in arrays and reshape them with the standard methods.
- Write functions with parameters and `return`, and choose arrow syntax when it fits.
- Model things as objects with properties and methods, and read `this` inside them.
- Select and rewrite the live page with the DOM, and react to clicks with `addEventListener`.

## 🎮 Practice Philosophy

Code is a machine you build by typing. The exercises keep that principle: every snippet runs
as written — the comments state the output you should actually get. When something looks
wrong, open DevTools and compare the real result with the expected one, line by line.

Every chapter ends with a project that is the whole chapter in one file — the shop receipt,
the dungeon die, the season pass, the combat log analyzer, the Guild Pass, the loot card
generator — so nothing stays as isolated trivia.
