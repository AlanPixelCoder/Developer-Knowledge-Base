## El Gremio de Gabinetes

En el trastienda del Gremio de Gabinetes hay filas de antiguas máquinas arcade para navegador. Cada partida empieza en frío: ranura de monedas en reposo, registro de servicio esperando. JavaScript permite hablar con esas máquinas, una instrucción a la vez, desde la consola hasta un HUD vivo.

## Ruta de Aprendizaje

1. **Arranque** — Despierta el gabinete con `console.log()`.
2. **Carga** — Guarda valores con variables y tipos.
3. **Puerta** — Bifurca con condicionales y dados.
4. **Enfriamiento** — Repite con bucles.
5. **Caja** — Organiza piezas en arrays.
6. **Rutinas** — Nombra el trabajo con funciones.
7. **Lista** — Agrupa datos y comportamiento con objetos.
8. **Panel** — Haz que el HUD responda a la entrada.
