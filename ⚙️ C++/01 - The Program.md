The programming language C++ (pronounced "C plus plus") was created by the Danish developer
**Bjarne Stroustrup** in 1979. Because it is an improvement on the C language, it was originally
named **"C with Classes"**.

Today it is one of the most famous programming languages because of its performance, control, and
reliability. It is found in:

| Domain | Examples |
| :--- | :--- |
| **Operating systems** | Windows, Linux |
| **Game development** | Fortnite, Grand Theft Auto |
| **Robotics & hardware** | Firmware, embedded controllers |
| **Web browsers** | Google Chrome, Safari |
| **Aerospace & crypto** | SpaceX flight software, Bitcoin |

It is widely taught in schools for its memory management, object-oriented programming, and the
fundamentals of how computer systems actually work.

## File structure

The code we write lives in C++ files, which use the **`.cpp`** extension. We write them in a **code
editor**: a text editor that can write, edit, and run code.

**Example (`main.cpp`):**

```cpp
#include <iostream>

int main() {
  std::cout << "Hello world!";
}
```

## The lineage

| Year | Language | Contribution |
| :--- | :--- | :--- |
| 1972 | C | Speed, manual memory control, close to the metal |
| 1979 | C++ | C plus classes, references, templates, RAII |
| 2000s | C++03 → C++11 | Modern era: `auto`, smart pointers, lambdas |
| 2020s | C++20 / C++23 | Concepts, ranges, modules, coroutines |

> [!TIP]
> Think of C++ as the engine behind Emberfall: fast, precise, and built to scale into a real
> product.

> [!NOTE]
> **Why learn the hard one first**
> C++ makes you manage memory and types explicitly. Every language you learn afterwards feels like
> it hands you those decisions back — but you will understand what it is doing on your behalf.
