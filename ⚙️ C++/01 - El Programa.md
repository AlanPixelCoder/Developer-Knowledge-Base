El lenguaje de programación C++ (se pronuncia "C plus plus") fue creado por el desarrollador danés
**Bjarne Stroustrup** en 1979. Como es una mejora del lenguaje C, originalmente se llamó
**"C with Classes"**.

Hoy es uno de los lenguajes más famosos por su rendimiento, control y fiabilidad. Está presente en:

- Sistemas operativos (Windows, Linux)
- Desarrollo de videojuegos (Fortnite, Grand Theft Auto)
- Robótica y hardware
- Navegadores web (Google Chrome, Safari)
- Software para los cohetes de SpaceX y Bitcoin

Se enseña en escuelas por su gestión de memoria, su programación orientada a objetos y por explicar
cómo funcionan los sistemas por dentro.

## Estructura de archivos

El código que escribimos vive en archivos C++ con extensión `.cpp`. Los escribimos en un **editor
de código**, que es un editor de texto capaz de escribir y ejecutar código.

**Ejemplo (`main.cpp`):**

```cpp
#include <iostream>

int main() {
  std::cout << "¡Hola mundo!";
}
```
