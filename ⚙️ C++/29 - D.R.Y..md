**"Don't Repeat Yourself" (DRY)** is a principle in software engineering aimed at reducing
repetition and writing good, clean code.

A **function** is like a mini-program inside your program: a reusable block of code that performs
a specific task. To execute — or **call** — it, write the function's name followed by parentheses:

```cpp
function_name();
```

Whether the task is 3 lines or 30, you can tuck it into a function and reuse it anywhere.

## Built-in Functions You Already Used

| Function | What it does |
| :--- | :--- |
| `std::rand()` | Generates a random number |
| `std::sqrt()` | Calculates a square root |
| `.push_back()`, `.pop_back()`, `.size()` | Vector operations |
| `int main()` | **The** function — the entry point of every C++ program |

> [!NOTE]
> **Why DRY actually matters**
> Repeated code means a bug has to be fixed in *every* copy — and one of them will be missed. A
> function gives a single place to fix, a single place to test, and a name that explains intent.

> [!TIP]
> If you catch yourself copying a block to a second location, that is the signal: extract it into
> a function and call it twice. See [[30 - Food Menu]] for the mechanics.
