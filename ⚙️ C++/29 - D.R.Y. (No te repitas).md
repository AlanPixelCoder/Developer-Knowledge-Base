**"Don't Repeat Yourself" (DRY)** — no te repitas — es un principio de la ingeniería de software
para reducir la repetición y escribir código limpio.

Una **función** es como un mini-programa dentro de tu programa: un bloque de código reutilizable que
realiza una tarea concreta. Para ejecutarla —o **llamarla**— escribe el nombre de la función seguido
de paréntesis:

```cpp
nombre_funcion();
```

Ya sea una tarea de 3 líneas o de 30, puedes guardarla en una función y reutilizarla donde quieras.

## Funciones integradas que ya usaste

| Función | Qué hace |
| :--- | :--- |
| `std::rand()` | Genera un número aleatorio |
| `std::sqrt()` | Calcula una raíz cuadrada |
| `.push_back()`, `.pop_back()`, `.size()` | Operaciones de vector |
| `int main()` | **La** función: el punto de entrada de todo programa C++ |

> [!NOTE]
> **Por qué DRY importa de verdad**
> El código repetido significa que un error hay que arreglarlo en *cada* copia — y alguna se
> olvidará. Una función da un único lugar donde arreglar, un único lugar donde probar y un nombre que
> explica la intención.

> [!TIP]
> Si te descubres copiando un bloque a un segundo lugar, esa es la señal: extráelo a una función y
> llámala dos veces. Ver [[30 - Menú de Comida]] para la mecánica.
