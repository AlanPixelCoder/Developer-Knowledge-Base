**Note:**
This module follows the rebuilding of the Emberfall Armory Console from the ground up. Starting with the decision to describe the interface from data, each chapter forges a new piece of the console until the full operations dashboard comes together — components, props, state, events, forms, effects, context, fetching, and routing all working in concert.

**Tip:**
Start at [[01 - The Rebirth]] and follow the build in order. Each lesson depends on the one before it, and by the end you'll assemble everything into the final console.

**Prerequisite:** [🟨 JavaScript MOC](../%F0%9F%9F%A8%20JavaScript/README.md). Familiarity with variables, functions, objects, arrays, and events is expected.
