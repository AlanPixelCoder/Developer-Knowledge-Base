**Note:**
Verdant Relay is a field-operations studio keeping beacons lit across relay poles. Every lesson builds from first principles with only Python's standard library: a next-token predictor, precise field briefs, a meadow index for semantic search, and a checklist for relay faults. The thread is simple — prediction by counting, specification by constraint, representation by vectors, and verification before acting.

**Tip:**
Start at **01** and trace each snippet by hand. The goal isn't to build a large model, it's to see the mechanisms clearly enough that failures stop looking mysterious.

**Prerequisite:** basic Python — lists, dictionaries, loops, `re`, `math`.
