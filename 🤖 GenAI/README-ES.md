**Note:**
Verdant Relay es un estudio de operaciones de campo que mantiene las balizas encendidas en una red de postes. Cada lección se construye desde cero con solo la biblioteca estándar de Python: un predictor del siguiente token, partes de campo precisos, un índice del prado para búsqueda semántica y una lista de verificación para fallas del relevo. El hilo conductor: predecir contando, especificar con restricciones, representar con vectores y verificar antes de actuar.

**Tip:**
Empieza por **01** y traza cada fragmento a mano. El objetivo no es construir un modelo grande, sino ver los mecanismos con claridad para que los fallos dejen de parecer misteriosos.

**Prerequisite:** Python básico — listas, diccionarios, bucles, `re`, `math`.
