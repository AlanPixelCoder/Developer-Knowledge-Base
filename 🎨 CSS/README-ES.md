**Nota:**
Este módulo es el Mapa de Contenidos (MOC) de las notas de CSS de este vault de Obsidian. CSS es el lenguaje que convierte la estructura de HTML en un videojuego: maquetación, colores, tipografía, fondos, el modelo de caja, posicionamiento y flexbox. Todos los ejemplos son mínimos y ejecutables tal cual: combínalos con los archivos iniciales de HTML y ábrelos en el navegador.

**Consejo:**
Empieza por [[01 - Fundamentos de CSS]]. Primero la anatomía de la regla y la cascada — luego selectores, colores y tipografía antes de tocar el modelo de caja. El espaciado y el posicionamiento son los dos lugares donde más roturas ocurren; presta atención extra a [[10 - Espaciado y Box Sizing]] y [[11 - Display y Posicionamiento]].

**Requisito previo:** el [módulo 🌐 HTML](../%F0%9F%8C%90%20HTML/README-ES.md). CSS estiliza el marcado, así que lee primero las notas de HTML — necesitas conocer los elementos antes de poder vestirlos.

> [!NOTE]
> **La narrativa de Emberfall**
> Todos los ejercicios de este módulo pertenecen al mismo proyecto ficticio: *Emberfall*, un
> roguelike. Las pantallas de título se vuelven secciones hero, los volantes de festival se
> vuelven tarjetas responsive, las fichas de personaje se vuelven estilos de formulario, los
> horarios de academia se vuelven prácticas de posicionamiento, y el proyecto final es un juego
> de cartas coleccionables con giro 3D. La sintaxis no cambia en absoluto — y ese es el punto:
> aprendes un solo vocabulario y lo reutilizas en todas partes.

## 🧭 Ruta de Aprendizaje

1. **Fundamentos de CSS** → aprende la regla, el selector y el enlace a la hoja de estilos.
2. **Colores y Medidas** → habla color en tres notaciones y dimensiona sin miedo.
3. **Selectores (1 y 2)** → apunta las reglas a exactamente los elementos que quieres.
4. **Pseudoelementos y Pseudoclases** → estiliza partes, estados y contenido generado.
5. **Fuentes y Texto / Fondos y Shorthands** → viste el contenido: tipo y pintura.
6. **Modelo de Caja y Bordes / Espaciado y Box Sizing** → la geometría de toda maquetación.
7. **Display y Posicionamiento** → flujo, anclas, fijaciones y apilamiento.
8. **Flexbox** → el sistema de distribución moderno que gobierna el CSS actual.

## 🎯 Lo que serás capaz de hacer

- Escribir una hoja de estilos desde cero y enlazarla con `<link rel="stylesheet">`.
- Seleccionar cualquier elemento de una página con selectores de tipo, clase, id, combinadores y atributos.
- Estilizar texto por completo: familias, pesos, tamaños, alineación y decoración.
- Elegir la notación de color y la familia de unidades adecuadas para cada trabajo.
- Construir e inspeccionar las cuatro capas del modelo de caja con las herramientas de desarrollo del navegador.
- Espaciar, centrar y dimensionar cajas con padding, margin y `box-sizing`.
- Colocar elementos con los cinco valores de `position` y ordenar solapes con `z-index`.
- Maquetar barras de navegación, secciones hero, rejillas y tarjetas con flexbox.
- Publicar una página completa — feed, archivo, academia o colección de cartas — con una sola hoja de estilos.

## 🎮 Filosofía de práctica

CSS es un modelo de caja y un sistema de distribución — si ves las capas, puedes maquetar cualquier cosa. Los ejercicios siguen ese principio: el fragmento de cada lección es copiable y pegable en un `styles.css` y observable en el navegador. Si algo no se ve bien, abre las DevTools e inspecciona el elemento: el diagrama de caja nombrará a los culpables (demasiado padding, margin que falta, box-sizing equivocado).

Cada proyecto incluye la estructura HTML que estiliza, para que compares lo que dice el marcado con lo que hace la hoja de estilos — línea a línea en lugar de adivinar.
