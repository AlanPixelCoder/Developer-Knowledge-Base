**Nota:**
Este módulo es el Mapa de Contenido (MOC) de las notas CSS. CSS es lo que hace legible el sitio público del **Observatorio Tideglass** en plena tormenta: alto contraste, tamaños tipográficos honestos, diseños que resisten una pantalla estrecha. HTML da la estructura (páginas de instrumentos, gráficas de mareas, horarios de visita, tabla de datos, formulario); CSS da la claridad.

**Consejo:**
Empieza en [[01 - Primer Amanecer en Tideglass]]. Aprende la regla y la cascada primero, luego selectores, colores y tipografía antes del modelo de caja. El espaciado, `display`, posicionamiento y flexbox son donde más errores de maquetación aparecen.

**Requisito previo:** el [módulo 🌐 HTML](../%F0%9F%8C%90%20HTML/README.md). CSS da estilo al marcado, así que conviene conocer los elementos antes de vestirlos.

> [!NOTE]
> **El Observatorio Tideglass**
> Todos los ejemplos siguen el mismo proyecto ficticio: una estación científica costera que resiste la sal, la niebla y la marejada. Balizas, marcas de tiza, señales de marea, luz de farol y cuerdas de amarre no son decoración — enseñan el mismo CSS que usarías en un sitio real y legible con datos.
