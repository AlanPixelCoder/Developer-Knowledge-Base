**Note:**
This module is the Map of Content (MOC) for the CSS notes in this Obsidian vault. CSS is the language that turns HTML structure into a game: layout, colors, typography, backgrounds, the box model, positioning and flexbox. Every example is kept minimal and executable as-is: pair it with the HTML starter files and open it in a browser.

**Tip:**
Start at [[01 - CSS Basics]]. Rule anatomy and the cascade first — then selectors, colors and typography before you touch the box model. Spacing and positioning are the two places most breakage happens; give [[10 - Spacing & Box Sizing]] and [[11 - Display & Positioning]] extra attention.

**Prerequisite:** the [🌐 HTML module](../%F0%9F%8C%90%20HTML/README.md). CSS styles markup, so read the HTML notes first — you need to know the elements before you can dress them.

> [!NOTE]
> **The Emberfall narrative**
> Every exercise in this module belongs to the same fictional project: *Emberfall*, a roguelike.
> Title screens become hero sections, festival flyers become responsive cards, character sheets
> become form styling, academy timetables become positioning drills, and the final project is a
> collectible card game with 3D flip. Nothing about the syntax changes — which is the point: you
> learn one vocabulary and reuse it everywhere.

## 🎯 Learning Path

1. **CSS Basics** → learn the rule, the selector and the stylesheet link.
2. **Colors & Measurements** → speak color in three notations and size things without fear.
3. **Selectors (1 & 2)** → aim rules at exactly the elements you mean.
4. **Pseudo-elements & Pseudo-classes** → style parts, states and generated content.
5. **Fonts & Text / Backgrounds & Shorthands** → dress the content: type and paint.
6. **Box Model & Borders / Spacing & Box Sizing** → the geometry of every layout.
7. **Display & Positioning** → flow, anchors, pins and stacking.
8. **Flexbox** → the modern distribution system that rules modern layouts.

## 🎯 What You'll Be Able To Do

- Write a stylesheet from scratch and link it with `<link rel="stylesheet">`.
- Select any element on a page with type, class, id, combinator and attribute selectors.
- Style text fully: families, weights, sizes, alignment and decoration.
- Choose the right color notation and unit family for the job.
- Build and inspect the four-layer box model with browser Developer Tools.
- Space, center and size boxes with padding, margin and `box-sizing`.
- Place elements with all five `position` values and order overlaps with `z-index`.
- Lay out nav bars, hero sections, grids and cards with flexbox.
- Ship a whole page — feed card, archive, academy or card collection — with one stylesheet.

## 🎮 Practice Philosophy

CSS is a box model and a distribution system — if you can see the layers, you can lay out anything. The exercises keep that principle: every lesson's snippet is copy-pasteable into a `styles.css` and observable in a browser. When something looks wrong, open DevTools and inspect the element: the box diagram will name the liars (too much padding, missing margin, wrong box-sizing).

Every project ships with the HTML structure it styles, so you compare what the markup says with what the stylesheet does — line by line instead of guessing.
