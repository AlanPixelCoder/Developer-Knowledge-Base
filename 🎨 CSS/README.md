**Note:**
This module is the Map of Content (MOC) for the CSS notes in this Obsidian vault. CSS is what makes the **Tideglass Observatory** public site legible in a storm: high contrast, honest type sizes, layouts that survive a narrow screen. HTML gives the station its structure (instrument pages, tide charts, visiting hours, a data table, a small form); CSS gives it clarity.

**Tip:**
Start at [[01 - Tideglass First Light]]. Learn the rule and the cascade first, then selectors, colors, and typography before touching the box model. Spacing, display, positioning, and flexbox are where most layout bugs hide.

**Prerequisite:** the [🌐 HTML module](../%F0%9F%8C%90%20HTML/README.md). CSS styles markup, so know the elements before you dress them.

> [!NOTE]
> **The Tideglass Observatory**
> All examples follow the same fictional project: a coastal science station weathering salt, fog, and swell. Beacons, chalk marks, tide signals, lantern light, and mooring ropes are not decoration — they teach the same CSS you would use on a real, readable data site.
