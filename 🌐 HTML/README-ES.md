**Nota:**
Este módulo es el Mapa de Contenidos (MOC) de las notas de HTML de este vault de Obsidian. HTML es el lenguaje que crea la estructura de cualquier página web — desde elementos y texto, hasta enlaces, imágenes, atributos, estilos, formularios y regiones semánticas. Todos los ejemplos son mínimos y ejecutables tal cual: abre el archivo en el navegador y funciona.

**Consejo:**
Empieza por [[01 - Fundamentos de HTML]]. Aprende a leer el marcado antes de aprender a darle estilo — cuando distingas claramente entre estructura y presentación, CSS te resultará mucho más fácil.

**Requisito previo:** ninguno. Es el primer módulo del track web y solo necesitas un editor de texto y un navegador moderno.

> [!NOTE]
> **La narrativa de Emberfall**
> Todos los ejercicios de este módulo pertenecen al mismo proyecto ficticio: *Emberfall*, un
> roguelike. Las barras de búsqueda se vuelven búsquedas en la wiki, los formularios de registro
> se vuelven creación de personajes, las maquetas se vuelven cuadrículas de equipamiento y los
> `<article>` se vuelven notas de parche. La sintaxis no cambia en absoluto — y ese es el punto:
> aprendes un solo vocabulario y lo reutilizas en todas partes.

## 🧭 Ruta de Aprendizaje

1. **Fundamentos de HTML** → Crea tus primeras páginas con texto, listas, enlaces e imágenes.
2. **Estructura y Atributos** → Organiza los archivos correctamente y etiqueta los elementos con `class` e `id`.
3. **Formularios** → Recoge datos del usuario y valida los campos en el navegador.
4. **HTML Semántico** → Sustituye los `<div>` genéricos por elementos que dicen lo que son.

---

## 🎯 Lo que serás capaz de hacer

- Escribir una página HTML5 completa con `<!DOCTYPE html>`, `<head>` y `<body>`.
- Usar encabezados, párrafos, listas, enlaces e imágenes correctamente.
- Etiquetar y dar estilo a elementos con atributos, `<style>` y selectores CSS.
- Crear formularios con campos validados, grupos de radio y casillas de verificación.
- Elegir el elemento adecuado para cada fragmento de contenido en lugar de recurrir al `<div>`.
- Escapar los caracteres especiales para que tu texto nunca se confunda con marcado.

## 🎮 Filosofía de práctica

Una página web es texto legible. Si puedes leer el marcado, puedes escribirlo. Los ejercicios siguen ese principio: abre el archivo en el navegador tras cada pequeño cambio. Si algo no se ve bien, usa las herramientas de desarrollo para inspeccionar el elemento y compara el HTML real con lo que escribiste.

Cada ejercicio incluye un archivo inicial (los comentarios te indican qué añadir) y una solución final, para que puedas comparar línea a línea en lugar de adivinar.
