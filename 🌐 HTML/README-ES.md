**Nota:**
Este módulo es el Mapa de Contenidos (MOC) de las notas de HTML de este vault de Obsidian. Situado en el **Observatorio Tideglass** sobre el muelle de cristal de Greyharbor, cada ejercicio construye parte del sitio público de la estación: registros del muelle, salas de instrumentos, formularios de admisión del puerto y boletines del astillero. HTML aporta la estructura; CSS y JavaScript vendrán después.

**Consejo:**
Empieza por [[01 - Cimiento del Muelle de Cristal]]. Aprende a leer el marcado antes de darle estilo — cuando distingas estructura y presentación, el resto será mucho más fácil.

**Requisito previo:** ninguno. Solo necesitas un editor de texto y un navegador moderno.

> [!NOTE]
> **Narrativa de Tideglass**
> El personal del observatorio necesita un sitio público para publicar lecturas de mareas, seguir boyas e instrumentos, aceptar solicitudes de admisión del puerto y publicar boletines del astillero. Cada capítulo hace crecer ese sitio un poco más, usando elementos HTML reales para un trabajo real en el muelle.

## 🎯 Ruta de Aprendizaje

1. **Cimiento del Muelle de Cristal** → Publica el registro matinal de mareas con texto, listas, enlaces e imágenes.
2. **Plano de Mareas** → Construye un esqueleto correcto, etiqueta tarjetas con clases/ID y crea anclas internas.
3. **Formularios del Puerto** → Recoge solicitudes estructuradas con validación y opciones agrupadas.
4. **Semántica del Astillero** → Dale al sitio puntos de referencia semánticos y marcado pensado para la accesibilidad.

---

## 🎯 Lo que serás capaz de hacer

- Escribir una página HTML5 completa con `<!DOCTYPE html>`, `<head>` y `<body>`.
- Estructurar registros con encabezados, párrafos, listas, enlaces e imágenes.
- Etiquetar y agrupar elementos con atributos, clases, ID y bloques de estilo.
- Crear formularios con campos validados, grupos de radio, casillas y etiquetas correctas.
- Elegir elementos semánticos para regiones, artículos, navegación y figuras.
- Escapar caracteres especiales para evitar confusiones entre texto y marcado.
